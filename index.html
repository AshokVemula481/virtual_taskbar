Features

Everything you need,
nothing you don't

Designed to be lightweight, fast, and visually stunning out of the box.

🪟

Live Window Tracking

Automatically detects and displays all open Win32 and UWP apps with their native system icons in real time.

✨

Glassmorphic UI

Modern semi-transparent dark panel with blur, smooth hover animations, and active window indicators.

👁

Live Window Previews

Hover over any app icon to see a real-time DWM thumbnail preview — just like the native taskbar.

🖱

Drag & Reorder

Reorder pinned and active app icons by dragging. Layout is saved automatically to JSON.

🚀

Silent Background Launch

Runs quietly via a VBScript launcher — no console window, no interruptions.

🔁

Auto-Startup

One-click setup to launch automatically on Windows startup using the built-in installer.

Installation

Up in 3 steps

Requires Python 3.9+ on Windows 10 or 11.

1

Clone the repository

git clone https://github.com/AshokVemula481/virtual_taskbar.git

2

Install dependencies

pip install -r requirements.txt

3

Launch the taskbar

Double-click VirtualTaskbar.vbs for a silent launch, or run python main.py directly.
